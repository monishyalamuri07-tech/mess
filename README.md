# Mess Pass PWA

📱 **Live Web App**: [https://monishyalamuri07-tech.github.io/mess/](https://monishyalamuri07-tech.github.io/mess/)

A Progressive Web App (PWA) simulation for the student Mess Pass verification system.

---

## 📲 How to Install as an App (Zero Glitch)

### On Android (Chrome / Brave / Edge)
1. Open the live link in Chrome: [https://monishyalamuri07-tech.github.io/mess/](https://monishyalamuri07-tech.github.io/mess/)
2. Tap the **INSTALL** button on the bottom banner (or tap `⋮` (Menu) → **Install app** / **Add to Home screen**).
3. The app is now installed on your home screen with its own icon and runs full screen without any browser bar.

### On iPhone / iPad (Safari)
1. Open the live link in Safari: [https://monishyalamuri07-tech.github.io/mess/](https://monishyalamuri07-tech.github.io/mess/)
2. Tap the **Share** button (the square with an arrow pointing up at the bottom).
3. Scroll down and tap **Add to Home Screen**.
4. Tap **Add** in the top right.
5. The Mess Pass app icon is now on your home screen.

## ✨ Features
- **Offline Capable**: Works without active internet inside hostel and mess dining halls via Service Worker caching.
- **Auto-Configured Profile**: Preloaded with student details and student photo.
- **One-Tap Meal Pass**: Tap Breakfast, Lunch, or Dinner to run the camera scanner simulation and generate the approved pass.
- **Audio Verification**: Real scan confirmation beep sound.
- **Verification Countdown**: 30-second live countdown timer with auto-return.
- **Offline QR Code**: Automatically caches and displays verification QR codes without network failures.
